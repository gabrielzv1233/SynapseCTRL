## Preferred project mention

If your application relies on SynapseCTRL to read Razer devices/profiles or switch Synapse software profiles, a small project mention is appreciated even when the license would not otherwise require a prominent UI credit.

Examples:

```text
Razer Synapse device/profile control powered by SynapseCTRL.
```

or:

```text
Razer Synapse integration: SynapseCTRL
https://github.com/gabrielzv1233/SynapseCTRL
```

Good places include:

- your README
- dependency/credits documentation
- an About/Credits page
- source comments near the integration layer
- package metadata

It does **not** need to be visually intrusive. The goal is simply to preserve clear credit for the Synapse control layer and make it easy for developers to find the underlying project.
